# NPU 学习路线

不要从缩写表开始死记。先问清楚三个问题：**东西在哪里、数据怎么走、谁负责控制**。

## 推荐顺序

1. [一张图理解 NPU](npu/mental-model.md)：区分 die、芯片、板卡、Device 和 AI Core。
2. [核心术语](npu/glossary.md)：把高频词放进同一套层级关系中。
3. [数据搬运与 H2D](npu/data-movement.md)：跟踪一个张量从 CPU 内存到计算单元再返回的过程。
4. [网络平面与出框口](npu/network-planes.md)：区分控制面、数据面、参数面、存储面和物理上行口。

## 学习时始终画两张图

- **物理拓扑图**：CPU、NPU、PCIe Switch、卡间互联、网卡和交换机分别在哪里。
- **数据路径图**：源内存、目标内存、经过的总线、执行搬运的引擎以及同步点是什么。

同一个词在硬件、驱动、通信库和集群网络中可能指向不同层次。遇到含糊表述时，先补充层次和方向，
例如把“数据很慢”改写成“Host DRAM 到 Device HBM 的 H2D 带宽低”。

## 约定

本文以通用 NPU 概念为主，并用昇腾常见术语帮助理解。不同产品代际的 AI Core 组成、内存层次、
互联协议和端口映射可能不同，具体配置应以对应产品手册为准。
